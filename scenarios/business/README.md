# Escenarios empresariales

El ejecutor utiliza las credenciales locales ignoradas por Git y nunca las
imprime. `SCN-005` genera un ajuste de umbral y lo compensa exactamente para no
alterar las existencias netas. `SCN-006` conserva un control de calidad fallido
como evidencia empresarial deliberada y atribuible al identificador de la
ejecución.
